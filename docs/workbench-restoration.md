# 文献工作台功能恢复

本轮变更：`restore-literature-workbench`。在现有 Python 文献服务、Node 应用会话和 React 消息流架构上恢复交互，不回退整次重构。

## 已恢复

- 内部文献项目列表、新建项目、项目文献增删、会话项目选择及侧栏分组。只读取应用数据目录中的文献工作区，历史无项目会话放在“未归属会话”。
- 原风格侧栏、文献库/Skills 导航、底部设置入口；桌面侧栏折叠及宽度记忆、移动导航。
- 文献卡片/列表、元数据和摘要概览、PDF/全文阅读。阅读模式、行定位和返回操作保留项目上下文。
- Claude Code/Codex 默认工具、可选模型及安装/登录状态。默认值持久化，仅影响新会话，切换工具清除旧模型。
- 新建和已有会话共用底部输入框，支持文献标签、项目草稿、会话草稿、中文组合输入、换行、发送失败恢复和停止。

## 架构与兼容

项目复用 `workspace/<项目名>/refs/papers.json`，不复制文献。会话新增可选 `projectId`，仍使用独立 CLI 执行目录、应用会话 ID 和原生续接 ID。项目名称当前同时作为标识，不支持重命名。

新建会话和执行检索时均校验项目及文献范围。空项目返回空上下文；不存在的项目和越界选择明确报错。全文检索在 LIMIT 之前限定项目，避免大量全库结果挤掉项目文献。超过 SQLite 参数数量限制的项目通过临时白名单表处理。

已有 `refs/papers.json`（包括旧列表格式）兼容读取；根级旧 `papers.json`、损坏索引和越界符号链接返回可诊断错误。没有重新执行生产数据迁移。

Skills 使用原配置 `SCHOLARAIO_SKILLS_DIR`，默认 `~/scholaraio/skills`。目录不存在时页面展示空状态。此入口提供浏览；已经移除的配置编辑、附件、语音和斜杠命令执行不在本轮恢复范围。

## 调试中修复的问题

- 分块检索白名单最初引用错误的 SQL 表，导致项目上下文查询失败；已改为明确选择元数据表或分块表。
- 首条回答在消息流续接前完成时，前端可能停留在旧快照；完成状态现在同步服务端消息。
- 创建会话期间输入框仍可编辑，文字可能留在即将切走的页面；创建期间改为只读，浏览器测试明确等待会话路由。
- 首条请求响应丢失时按稳定消息 ID 查询是否已接收，避免盲目重发；真正失败保留草稿。
- 阅读模式切换和行定位不再覆盖项目查询参数。

## 原控件与交互校正（2026-09-21，进一步恢复）

本轮按用户最新要求重新限定边界：AI SDK / Streamdown / Pierre Diffs 继续负责统一会话消息；文献检索、阅读、导航和输入控件直接复用 63fd364 的原组件，不再把简化这些页面视为消息重构的一部分。

- **实际入口纠正**：63fd364 的 `/library` 挂载的是 SearchPage。现已恢复原检索标题、模式下拉、排序胶囊、卡片/列表图标、多选模式和详情抽屉。上一轮分析页改到 `/library?view=analysis`；导入/项目管理保留在 `manage=1` 的显式入口。
- **真实接口适配**：SearchPage 通过小型适配模块接入当前受管理库；作者、关键词、综合、语义模式接到对应服务。项目白名单在检索前应用，空项目保持空结果。语义依赖不可用时明确报错，综合模式回退时明确提示。原批量加入 Workspace / 新建并加入交互使用真实内部项目；成功后更新成员数。
- **卡片与详情**：直接使用原 PaperGridCard、PaperVirtualList / PaperListRow；默认点选打开抽屉，多选状态点选勾选。恢复完整图片列表，过滤越界符号链接；Esc 关闭抽屉，关闭状态不参与键盘导航。返回阅读前页面保留检索词、模式、视图、排序和项目。
- **导航和会话**：恢复 Library、PanelLeftOpen、FolderOpen 等原图标与紧凑 Workspaces 分组；新建会话欢迎文案、建议按钮、项目论文标签和 830px composer 宽度按原组件布局恢复；设置依用户要求固定底部。
- **输入控件**：复用原 SendActionButton、ModelSwitcher、ModeSelector、VoiceInputButton/useSpeechRecognition。恢复权限模式和思考模式的真实执行参数、已有会话模型切换。模型改变后在下轮续接原生会话，不丢失应用消息；当前运行中禁止修改。语音仅在用户点击后启动，离开页面会释放识别对象。

### 仍需继续恢复的差异

本轮不是全部功能恢复完成。原 composer 附件上传/排队、斜杠命令与科研 skill 激活、会话项目文件区尚未接到应用自有会话接口；旧 Projects / Agents 页面及其会话管理操作仍需逐项确认哪些应在“仅内部文献项目”的范围内保留。旧设置中已删除的配置编辑功能按用户此前允许保持移除。后续应沿原组件适配这些接口，不能再次用静态按钮或不执行的控件代替。

## 会话样式与交互对齐（2026-09-22）

以 63fd364 实际运行页面并排对照（旧版以隔离数据目录临时启动），仅保留“统一 AI 消息格式 + 第三方渲染”这一重构目标，其余外观和交互回到原组件。

- **消息区**：`SessionMessages` 改用原 `message-list` / `user-prompt-container` / `assistant-turn` / `timeline-item` / `tool-row` / `thinking-block` 样式类（样式现集中在 `features/session/session.css` 与 `session-markdown.css`，见 `.claude/topics/agent-rendering.md`）。文本仍由 Streamdown 渲染，工具行是单一通用组件（名称 + 摘要 + 展开查看输入/输出/Pierre 差异），未恢复旧的逐工具渲染树与服务端 HTML 增强。恢复复制按钮、长消息 Show more、Thinking 折叠、处理中打字指示和“Queued (next)”排队气泡。
- **会话页**：原头部（标题、provider · model、状态胶囊、会话文件/项目文献图标按钮）、`tool-approval-fixed` 审批浮层、连接状态条和 `session-input` 底栏。审批恢复 Approve / Approve + Accept Edits / Deny；服务端 `/input` 新增 `approve_accept_edits`，批准后把进程与会话权限模式切到 acceptEdits。
- **新对话页**：标题回到布局标题栏（项目名或 New Chat）；无项目显示原欢迎区与建议，项目内显示文献胶囊、选中后出现科研 skill 胶囊（按单篇/多篇约束禁用），选中文献以徽标显示在输入框上方，skill 以原 SlashCommandBadge 呈现并把文献 ID 作为参数。移除原版没有的页面级项目/AI 工具下拉和“更多会话操作”；AI 工具取设置默认值，项目取自侧栏入口。新对话与原版一样只显示思考模式，权限模式在会话中调整。
- **Composer**：恢复原 MessageInput 排布——左侧附件（带数量角标）、权限/思考胶囊、语音；右侧模型选择与发送/排队/停止。语音识别中边框变红，Ctrl+Enter 排队，候选列表支持 Home/End。移除原版没有的“/”按钮。
- **侧栏与 Skills**：原 SidebarSection 标题/计数样式、项目分组缩进、相对时间（今天/n天前）、加载与“暂无对话”状态；Skills 详情恢复 Send 图标的“插入到会话”（现在可用，跳转新对话并插入命令），复制状态自动复位。
- **CLI 历史导入**：从新对话页移到设置页 History 区，按当前默认工具导入只读会话。

验证：lint、类型检查、客户端 44 项测试、会话 API 19 项测试（新增 accept-edits 审批用例）通过；Playwright 8 项浏览器流程全部通过（本机无 uv，测试时以指向现有 dev Python 运行时的临时 `SCHOLARAIO_HUB_UV` 替身启动测试服务）。另修正了附件改动后未同步的 `sessionApi.begin` 单元测试期望。
